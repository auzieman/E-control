# Release notes

## 0.1.0 — 2026-10-17

First public preview of the native EFL workstation control panel for Alpine/X11.

- Focused sidebar pages following the active desktop theme.
- Live audio, display, NetworkManager, BlueZ, account and firewalld integrations.
- Embedded appearance selectors with a version-matched Enlightenment bridge.
- CUPS printer actions, OpenRC service controls, storage usage and system reports.
- Authenticated helper, guarded display/network trials and read-only backend audit.

Validation: native Alpine build, 76 unit tests, 18 live read-only provider checks.
Theme switching still requires live validation after loading the current bridge.
See README for dependencies, supported actions, optional handoffs and limitations.
